# Hiraganized

## How it works

1. Press the global capture hotkey.
2. Drag to select a region of the screen containing Japanese text.
3. The selected region is scanned and each kanji (and compounds) is looked up, then shown in a compact popup.

## Features

- **Screen-region OCR** powered by [manga-ocr](https://github.com/kha-white/manga-ocr), tuned for Japanese text.
- **Online kanji lookups** via [kanjiapi.dev](https://kanjiapi.dev) for single characters and [Jisho](https://jisho.org) for compounds.
- **Per-kanji breakdown** with on'yomi / kun'yomi readings, meanings, and JLPT level.
- **Tray-based, always-ready** with a configurable capture hotkey.

## Installation

Download and run the latest [release](https://github.com/soulfern/Hiraganized) and complete the installation process.
